# Помидор: таймер Pomodoro для Android

Таймер фокуса и перерывов по технике Pomodoro на Jetpack Compose. Круговой прогресс, цвет экрана под фазу и счётчик помидоров за день.

## Возможности
- Циклы «фокус → короткий перерыв», после четырёх раундов фокуса длинный перерыв
- По умолчанию 25 минут фокуса, 5 минут короткого и 15 минут длинного перерыва
- Кнопки «Старт» / «Пауза», «Сбросить» и «Пропустить»
- Номер раунда в фазе фокуса («Раунд 2 из 4»)
- Круговой прогресс нарисован на Canvas
- Фон плавно меняет цвет под фазу: красный, зелёный, синий
- Настройка длительностей кнопками −/+: фокус 5..90 мин (шаг 5), короткий перерыв 1..30 мин (шаг 1), длинный 5..60 мин (шаг 5)
- Пока таймер стоит, новая длительность сразу применяется к текущей фазе
- Счётчик завершённых помидоров за сегодня с правильным склонением и рядом 🍅
- Пропущенный фокус не засчитывается
- Настройки и счётчик сохраняются между запусками, счётчик обнуляется на следующий день
- Экран не гаснет, пока идёт таймер

## Стек
Kotlin 2.0, Jetpack Compose (BOM 2024.09), Material 3, AndroidX ViewModel, Kotlin Coroutines, `StateFlow`, SharedPreferences. minSdk 26, targetSdk 34, Android Gradle Plugin 8.5, Gradle 8.7, JDK 17.

## Как запустить
Через Android Studio (Koala или новее):
1. Откройте папку `android-pomodoro-timer` как проект.
2. Дождитесь синхронизации Gradle: нужная версия Gradle скачается по `gradle/wrapper/gradle-wrapper.properties`.
3. Запустите на эмуляторе или телефоне кнопкой Run.

Из терминала (нужны установленные Gradle и Android SDK). Скрипта `gradlew` в репозитории нет, его нужно один раз сгенерировать:
```bash
gradle wrapper --gradle-version 8.7
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug   # установка на подключённое устройство
```

## Настройка
Значения по умолчанию и число раундов до длинного перерыва задаются в `Settings` в `TimerViewModel.kt`. Границы для кнопок −/+ находятся в `changeSetting()`, шаг изменения в `MainActivity.kt` (вызовы `Stepper`). Цвета фаз задаёт функция `phaseColor()` в `MainActivity.kt`.

## Структура проекта
```
app/src/main/java/com/whysafe/pomodoro/
├── MainActivity.kt      # экран таймера: прогресс на Canvas, кнопки, настройки

app/src/main/res/        # строки, тема, иконка
```

## Как это устроено
- `TimerViewModel` хранит всё состояние в одном `StateFlow<TimerState>`, экран только отображает его через `collectAsStateWithLifecycle`.
- Тикер работает в корутине `viewModelScope` и обновляет состояние каждые 200 мс.
- Остаток считается от момента окончания по монотонным часам `SystemClock.elapsedRealtime()`, поэтому задержки `delay()` не накапливаются и смена системного времени не влияет на отсчёт.
- Переход между фазами в одной функции `moveToNext()`: после каждого `roundsBeforeLong`-го фокуса выбирается длинный перерыв.
- Экран не гаснет благодаря `view.keepScreenOn` в `DisposableEffect`, флаг снимается при паузе.
- Цвет фона анимируется через `animateColorAsState`.

## Идеи для развития
- Foreground-сервис с уведомлением, чтобы таймер шёл в фоне
- Звук или вибрация по окончании фазы
- Статистика по дням
